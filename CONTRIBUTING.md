# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

## Contributions Welcome

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository to your GitHub account.
2. Create a new branch for your changes.
3. Make your improvements or bug fixes.
4. Commit your changes with a clear message.
5. Push your branch to GitHub.
6. Submit a pull request for review.

## Reporting Bugs

Please describe the issue, explain how to reproduce it, and provide relevant information.

## Suggestions and Enhancements

We welcome suggestions for new features, improvements, and better documentation.

## Code of Conduct

All contributors are expected to follow the project's CODE_OF_CONDUCT.md.
